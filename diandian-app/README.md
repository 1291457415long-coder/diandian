# 点点（Diandian）— 离线血糖 / 体重记录 App

基于 Stitch 导出的「点点」UI 原型实现的可安装离线手机 App（PWA）。

## 特性

- **完全离线**：数据保存在手机本地（IndexedDB），无账号、无登录、无云同步、无广告
- **血糖记录**：超大数字键盘、6 种固定场景（空腹/餐前/餐后30分钟/餐后1小时/餐后2小时/随机）、场景必选
- **体重记录**：同一天可记多次，首页显示最新一次 + 较上次变化
- **餐后提醒**：仅餐前可设置（30分/1小时/2小时/不提醒），从餐前记录时间计时；只保留最新一顿的未触发提醒；到期发送一次系统通知并自动结束；点击通知直达快速记录（自动带出场景与食物）；提前记录餐后自动取消对应提醒
- **智能关联**：餐后血糖自动寻找最近且时间合理的餐前建立关联（App 自行判断，不硬编码）；随机血糖不参与关联
- **数据可靠**：删除餐前→提醒取消、餐后保留并解除关联；修改餐前时间→提醒自动重算；关联不合理时弹窗让用户选择「保持/解除」
- **单位全局切换**：血糖 mmol/L ↔ mg/dL、体重 公斤 ↔ 斤（1 公斤 = 2 斤），内部保存标准值，切换不丢精度
- **交互式趋势图**：血糖默认当天、体重默认近30天；支持拖动平移、双指/按钮缩放、点按数据点看详情（时间/数值/场景/吃了什么）；只用真实数据
- **深色模式**：跟随手机系统自动切换
- **数据导出**：一次导出全部血糖+体重（含每条记录的「吃了什么」），CSV + UTF-8 BOM，调起系统分享菜单
- **历史记录**：按日期分组、每天最新→最旧；详情页显示完整信息
- **吃了什么**：在记录页直接手动输入，多个用逗号/顿号分隔（如「米饭、番茄炒蛋」），保存为名称快照随记录走；只记录名称，不做热量/营养计算（原「食物库」已移除）
- **视觉**：继承 Stitch 设计（深海军蓝 #1A2B3C、冷灰背景、Manrope/JetBrains Mono、8px 网格、圆角体系、时间线列表、极简裸图表）；深色模式仅跟随系统，无按时间自动切换

## 在手机上安装（3 步）

1. **启动本地服务器**：电脑上执行 `node serve.js`（或 `node serve.js 8080`），看到局域网地址 `http://<电脑IP>:8080`
2. **手机打开**：手机与电脑连同一 Wi-Fi，用浏览器（Chrome/Safari）打开该地址
3. **添加到主屏幕**：
   - Android Chrome：右上菜单 ⋮ → **添加到主屏幕**
   - iPhone Safari：**分享 → 添加到主屏幕**
   - 首次设置餐后提醒时允许「通知」权限（若不弹，到设置页点「开启通知」）

> 也可以把整个文件夹部署到任意静态托管（HTTPS）后安装。安装后完全离线可用，断网不影响任何功能。

## 数据存储与提醒机制说明

- 所有数据存入浏览器 IndexedDB（`diandian-db`），无网络请求
- 提醒记录独立存储（不产生“未完成”健康记录）：`{ premealGlucoseId, minutes, targetTime, canceled, triggered }`
- 通知策略（尽可能可靠）：
  - App 在前台：每 30 秒 + 回到前台时检查到期提醒，发送一次即标记触发
  - App 被清理 / 手机重启：Service Worker 激活或下次打开 App 时自动补发到期提醒（不重复）
  - 通知权限关闭：首页与设置页提示，并提供开启入口

## 主要路由

| 路由 | 页面 |
| --- | --- |
| `#/home` | 首页（今日血糖 / 最近体重 / 快捷按钮 / 提醒倒计时） |
| `#/quick/glucose` | 血糖快速记录（支持 `?edit=` 编辑、`?scenario=&premeal=` 通知直达） |
| `#/quick/weight` | 体重快速记录（支持 `?edit=` 编辑） |
| `#/history` | 历史（`?type=glucose|weight`） |
| `#/trend` | 趋势图（`?type=glucose|weight`） |
| `#/glucose/:id`、`#/weight/:id` | 记录详情 |
| `#/reminder/:id` | 提醒详情（修改 / 取消） |
| `#/settings` | 设置（单位 / 通知 / 导出） |
