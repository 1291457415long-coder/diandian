# 点点（Diandian）App — 交付总览

## 做了什么

把 Stitch 导出的「点点」UI 原型实现为一个**真正能在手机上运行的离线 App**（可安装 PWA），而不是把 HTML 包装成网页壳。

**交付位置**：`C:\Users\WIT_User\WorkBuddy\2\diandian-app\`
**技术形态**：原生 HTML/CSS/JS 单页应用 + IndexedDB 本地持久化 + Service Worker 本地通知 + 自研 SVG 交互图表；无任何网络依赖、无账号、无广告。

## 保留的 Stitch 设计

- 完整色彩体系（浅色：冷灰 #F7FAFC + 深海军蓝 #1A2B3C；深色：午夜蓝 #0F172A，跟随系统）
- 排版（Manrope / JetBrains Mono 体系 + 数字 tabular-nums）、8px 网格、圆角（12/16px 卡片、胶囊按钮）
- 首页时间线列表、倒计时提示条、体重大数字卡片、快捷按钮
- 快速记录页超大数字键盘、场景标签、底部固定保存栏
- 趋势页极简裸图表 + 血糖/体重切换
- 设置页通知横幅、单位行、导出按钮
